# Drone Delivery REST Service

A REST service for a drone delivery system, built as part of my Computer Science degree at the University of Edinburgh.

## What it does

* Provides endpoints for drone information and availability
* Calculates distances and checks whether locations are within regions
* Calculates delivery paths for available drones
* Uses JSON for requests and responses
* Connects to an external service using an environment variable
* Packaged and run using Docker

## Testing

REST endpoints were tested using Postman and cURL.

## Technologies

Java, Spring Boot, Docker, REST, JSON
